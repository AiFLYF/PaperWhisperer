§01理念manifesto

三小时的泛读，
压成一次提问。

泛读一篇论文，你要翻摘要、找图表、辨贡献、记局限——每步都在和排版搏斗。 PaperWhisperer 把这件事拆成六段并发的抽取任务：共享同一份文档上下文， 先跑完的先显示，长任务随时取消。你只需要读结论，然后追问。

↖ 不重复读文档，只排一次队

§02能力what you get

六段输出 · 目录

01结构化摘要 自动提炼核心观点，按背景、方法、结论分层输出，一眼握住全文脉络。 Overview 02关键引用 提取最值得引用的原句、定义与结论，保留原文措辞，不做泛泛改写。 Key Citations 03文本结构 研究问题、核心方法、实验论证、关键结论与局限，层级三到四层。 Text Structure 04视觉图谱 输出可渲染的 Mermaid 结构图，节点不超过 20 个，支持 SVG 导出进汇报材料。 Visual Map 05批判评价 贡献、历史地位、优点、局限与可学习之处——审稿视角，而非复述结论。 Evaluation 06深度简报 证据—结论链、复现检查清单与推荐检索关键词，直接用于组会和综述。 Research Brief

    追问

    四个角度继续深入，基于同一上下文

追问角度

Evidence依据

先给直接结论，再列出文档依据、可推断内容与不确定处。

Explain讲解

分步骤解释概念、方法和公式，必要时补充类比。

Critique批评

从贡献、假设、局限、效度威胁到可改进点做批判分析。

Reproduce复现

输出复现步骤、关键变量、数据依赖与检查清单。

§03接入get it running

两条命令，
剩下的交给它。

# 安装依赖 $ pip install -r requirements.txt # 配置服务端口（OpenAI 兼容协议均可） $ cp .env.example .env OPENAI_API_KEY=sk-your-key OPENAI_BASE_URL=https://api.openai.com/v1 OPENAI_MODEL=gpt-4o-mini # 启动 $ python web_app.py # 浏览器打开 http://localhost:5000
  • Python 3.10+ 与 pip
  • OpenAI 兼容协议的服务端点
  • 单文件上限 16 MB
  • 可选 SEMANTIC_SCHOLAR_API_KEY 提升检索限额

检索与引用

Semantic Scholar 与 arXiv 双源检索；导入公开 PDF 后直接进入同一条分析链路。

会话与安全

session_token 只在分析响应中返回；远程下载拒绝私网与环回地址；会话默认 24 小时过期；默认不持久化完整正文。

接口

  1. POST/api/analyze上传并分析
  2. POST/api/analyze/streamSSE 流式分析
  3. POST/api/ask基于 session 追问
  4. POST/api/ask/stream流式追问
  5. POST/api/search-papers检索论文
  6. POST/api/import-paper导入公开 PDF
  7. POST/api/reading-queue保存阅读队列
  8. POST/api/recommend-papers延伸阅读推荐
  9. GET/api/download-paper代理下载原文
  10. GET/api/health运行状态探活
