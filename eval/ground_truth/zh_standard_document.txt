信息技术　文档解析质量评测规范
第 1 部分：术语与评测框架（征求意见稿）
1 范围
本文件规定了文档解析系统的质量评测术语、评测语料构成、指标定义与判定规则，适用于数字原生文档与扫描文档的解析质量评测。
2 规范性引用文件
下列文件中的内容通过文中的规范性引用而构成本文件必不可少的条款。其中，注日期的引用文件，仅该日期对应的版本适用于本文件。
3 术语和定义
3.1 解析单元 source unit
文档中被解析系统识别的最小来源单位，如 PDF 的页、PPTX 的幻灯片、DOCX 的节。
3.2 定位符 source locator
用于将解析结果中的元素映射回原始文档位置的信息集合。
3.3 降级 fallback
当默认解析路径质量不达标时切换到替代路径的过程。
3.4 静默截断 silent truncation
解析结果丢失原文内容但未向用户提示的情形。
4 评测语料构成
评测语料应覆盖数字原生 PDF、双栏论文、扫描件、公式密集文档、表格密集文档、中英混排文档、DOCX、PPTX 与异常文件九类。
类别 / 配额 / 主要关注点 ; 数字原生 PDF / 17 / 基线质量与阅读顺序 ; 扫描件 / 11 / OCR 准确率与降级 ; 中英混排 / 4 / 多语言词法检索 ; 异常文件 / 3 / 错误处理与安全性
5 判定规则
出现任一硬失败信号即判定该文档解析失败；出现两个及以上警告信号应触发降级。静默截断在正式发布版本中的允许次数为零。
