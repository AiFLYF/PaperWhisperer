# This file is a POINTER, not a dependency list.
#
# pyproject.toml is the single authoritative dependency list. This file used to
# duplicate its base deps by hand and had already drifted: it carried pytest (a
# dev extra) while omitting httpx and ruff (also dev extras), and it omitted the
# `parse` extra's docling entirely. Two hand-kept lists that disagree are worse
# than one that is merely open, because the drift is silent.
#
# So there is nothing to keep in sync: the single editable requirement below
# makes pip resolve every dependency out of pyproject.toml. Adding a package
# name back into this file would reintroduce the second source of truth, and
# `make check-deps` fails the build if you try.
#
# There IS a lock file: `uv.lock`, tracked at the repository root. Nothing in
# this file reads it -- `pip install -r requirements.txt` resolves the `>=`
# floors and ignores it -- so `make install` is NOT reproducible. Use
# `make install-locked` when the version set is the thing being relied on.
#
#   * `docling>=2.0` (the `parse` extra) spans a 2.x range whose minors change
#     DoclingDocument output, so T0.9's bake-off report can only be reproduced
#     from the lock, never from this file.
#   * An earlier version of this header said a lock could not be generated from
#     this checkout, because docling is not installed here and `pip freeze`
#     would therefore omit the parse extra. That was true of `pip freeze` and
#     never true of `uv lock`, which resolves from pyproject.toml's metadata
#     rather than from the environment it runs in -- which is why the lock
#     covers docling and its torch chain on a machine that has neither.
#
# See `make lock-help`.
-e .

# The VERSION LOCK is `uv.lock`, generated from this project's pyproject.toml.
# It pins all 170 transitive packages, including the extras that are easy to
# forget: docling and its torch chain, pypdfium2 for page rendering, psycopg
# for the Hosted tier. Reproduce with:
#
#     uv lock                  # refresh, after changing pyproject.toml
#     uv sync --locked         # install exactly what the lock records, or fail
#
# `--locked` rather than `--frozen`, and CI uses it: `--frozen` installs the
# lock without checking it against pyproject.toml, so a dependency added there
# and never locked would install nothing and say nothing. `--locked` fails
# instead, which is the only version of this that keeps the lock honest.
