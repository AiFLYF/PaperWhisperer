# This file is a POINTER, not a dependency list.
#
# pyproject.toml is the single authoritative dependency list. This file used to
# duplicate its base deps by hand and had already drifted: it carried pytest (a
# dev extra) while omitting httpx and ruff (also dev extras), and it omitted the
# `parse` extra's docling entirely. Two hand-kept lists that disagree are worse
# than one that is merely open, because the drift is silent.
#
# So there is nothing to keep in sync: the single editable requirement below
# makes pip resolve every dependency out of pyproject.toml. Adding a package
# name back into this file would reintroduce the second source of truth, and
# `make check-deps` fails the build if you try.
#
# There is no lock file. Dependencies are `>=` floors, not pinned versions, so
# `make install` is NOT reproducible -- see the T0.8 handoff notes. Two
# consequences worth knowing before relying on this:
#
#   * `docling>=2.0` (the `parse` extra) is unpinned across a 2.x range whose
#     minors change DoclingDocument output. T0.9's bake-off report is therefore
#     not reproducible from this file; it needs a pinned environment, recorded.
#   * A lock file cannot be generated from this checkout as it stands: docling
#     is not installed here, so `pip freeze` would emit a pin set that silently
#     omits the parse extra -- the exact failure this file was rewritten to
#     prevent. Generating one requires an environment where the extras are
#     actually installed.
#
# See `make lock-help` for the intended lock workflow.
-e .

# The VERSION LOCK is `uv.lock`, generated from this project's pyproject.toml.
# It pins all 170 transitive packages, including the extras that are easy to
# forget: docling and its torch chain, pypdfium2 for page rendering, psycopg
# for the Hosted tier. Reproduce with:
#
#     uv lock                 # refresh, after changing pyproject.toml
#     uv sync --frozen        # install exactly what the lock says
#
# Until this file existed, `docling>=2.0` was the largest reproducibility
# hazard in the project: docling 2.x minors change DoclingDocument's output
# shape, and T0.9's bake-off requires a report that can be reproduced.
